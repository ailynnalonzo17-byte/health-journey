# Activity MET values

`kcal burned = MET × body weight (kg) × hours`. From the Compendium of Physical Activities. Watch or machine numbers override these when given.

| Activity | MET |
|---|---|
| Walking, easy (2.5 mph / 4 km/h) | 3.0 |
| Walking, moderate (3 mph / 4.8 km/h) | 3.5 |
| Walking, brisk (3.5–4 mph / 5.6–6.4 km/h) | 4.3–5.0 |
| Walking uphill / incline treadmill | 6.0 |
| Jogging (5 mph / 8 km/h) | 8.3 |
| Running (6 mph / 9.7 km/h) | 9.8 |
| Cycling, leisure (<10 mph) | 4.0 |
| Cycling, moderate (12–14 mph) | 8.0 |
| Stationary bike, moderate | 6.8 |
| Elliptical, moderate | 5.0 |
| Stair climber | 9.0 |
| Swimming, moderate laps | 5.8 |
| Strength training, moderate | 3.5 |
| Strength training, vigorous | 6.0 |
| HIIT / circuit | 8.0 |
| Yoga, hatha | 2.5 |
| Pilates | 3.0 |
| Dancing, aerobic | 7.3 |
| Zumba | 5.5 |
| Hiking | 6.0 |
| Housework, general cleaning | 3.3 |
| Gardening | 3.8 |
| Steps only (no activity named) | ~0.04 kcal per step per 70 kg, scaled by weight |
